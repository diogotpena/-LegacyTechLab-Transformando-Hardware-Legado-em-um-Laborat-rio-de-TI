# 04 --- Comparativo das Distribuições Linux

## Contexto

A escolha da distribuição Linux foi uma das primeiras decisões técnicas
do projeto.

Foram consideradas principalmente distribuições do ecossistema
Debian/Ubuntu, levando em conta estabilidade, documentação, facilidade
de administração e compatibilidade com o hardware.

## Debian 12

### Pontos positivos

-   estabilidade;
-   forte presença em servidores;
-   ampla documentação;
-   grande ecossistema;
-   excelente plataforma para aprendizado de administração Linux.

### Considerações

Dependendo da configuração escolhida, pode exigir maior familiaridade
inicial com administração e configuração do sistema.

## Ubuntu

### Pontos positivos

-   ampla comunidade;
-   documentação extensa;
-   grande disponibilidade de tutoriais;
-   forte presença profissional;
-   amplo ecossistema de pacotes e ferramentas.

## Xubuntu

O Xubuntu utiliza o ecossistema Ubuntu com o ambiente gráfico Xfce,
sendo uma alternativa adequada para equipamentos com recursos mais
limitados.

### Pontos considerados

-   interface gráfica relativamente leve;
-   compatibilidade com o ecossistema Ubuntu;
-   facilidade de uso;
-   possibilidade de utilizar o equipamento como estação Linux para
    estudos.

## Decisão

O projeto adotou inicialmente o **Xubuntu 24.04**.

A decisão foi baseada no equilíbrio entre:

``` text
Hardware disponível
+
Leveza do ambiente
+
Objetivo de aprendizado
+
Ecossistema Ubuntu
```

A adequação definitiva será avaliada durante os testes no próprio
equipamento.
