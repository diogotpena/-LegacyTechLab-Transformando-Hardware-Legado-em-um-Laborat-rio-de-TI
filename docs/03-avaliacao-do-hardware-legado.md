# 03 --- Avaliação do Hardware Legado

## Objetivo

Avaliar a viabilidade de reutilizar um notebook antigo como laboratório
de Tecnologia da Informação.

## Possíveis funções

O equipamento poderá ser utilizado, conforme os testes de desempenho,
para:

-   estação Linux;
-   administração de sistemas;
-   cliente SSH;
-   estudos de terminal e Bash;
-   diagnóstico de redes;
-   serviços leves;
-   automação;
-   ferramentas de Cloud;
-   estudos introdutórios de segurança e hardening.

## Limitações

Não é objetivo inicial utilizar o equipamento para:

-   múltiplas máquinas virtuais pesadas;
-   processamento intensivo;
-   serviços que exijam grande quantidade de memória;
-   workloads incompatíveis com o processador.

## Estratégia

A estratégia do LegacyTechLab é adaptar o laboratório ao hardware:

``` text
Hardware legado
      ↓
Identificação dos recursos
      ↓
Escolha de software adequado
      ↓
Testes práticos
      ↓
Medição dos resultados
      ↓
Expansão do laboratório
```

## Conclusão

O hardware é considerado adequado para iniciar um laboratório Linux,
desde que as atividades sejam dimensionadas de acordo com suas
limitações.
