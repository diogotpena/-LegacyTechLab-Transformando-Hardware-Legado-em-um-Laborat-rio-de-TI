# 05 --- Decisão pelo Xubuntu

## Distribuição escolhida

A distribuição inicialmente selecionada para o LegacyTechLab é o
**Xubuntu 24.04**.

## Motivações

A escolha considera:

-   hardware legado;
-   8 GB de RAM;
-   Intel Core i3 de primeira geração;
-   necessidade de uma interface gráfica adequada ao equipamento;
-   objetivo de estudar Linux na prática;
-   acesso ao ecossistema Ubuntu.

## Papel do Xubuntu no projeto

O Xubuntu representa a base inicial do laboratório. Ele não limita a
evolução futura do projeto.

A partir do ambiente Linux, o laboratório poderá receber experimentos
relacionados a:

-   administração de sistemas;
-   redes;
-   infraestrutura;
-   Cloud;
-   cibersegurança;
-   automação;
-   troubleshooting.

## Estado da implementação

A mídia USB foi criada e o equipamento conseguiu realizar boot por ela.

A instalação avançou até a etapa de particionamento, onde foi
identificado um problema durante a criação da partição `ext4`.

Portanto, a instalação ainda não está concluída.
